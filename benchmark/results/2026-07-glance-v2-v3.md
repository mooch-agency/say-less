# Results: glance benchmark, v2, v3, and the pivot to cheap spot checks

Session of 2026-07-19. Follow-on from 2026-07-channel-comparison.md and the
scope-hook rounds in 2026-07-scope-hook-report.md.

## Reframing (from Tahi)

Adherence was never the problem: v1 reliably kills em dashes, openers, hedges.
The residual verbosity is the SPEC. The real goal: the overwhelmed AI-builder
gets the outcome immediately and actually reads it. Operationalised: replies at
the length of the style file's own examples (roughly 5-40 prose words), outcome
in line 1.

## Glance benchmark (glance_bench.py)

Single-turn, scores: outcome_first (judge reads only line 1), words,
completeness; headline glance_pass = outcome-first AND complete.

- **Judge bug (fixed):** judges originally ran in the repo cwd, inheriting the
  project's Say Less hook + output style, and parsed raw stdout that returned
  empty on hiccups. Result: ~70% of completeness scores were 0 ("5432." scored
  0). Fix in `claude_plain`: hermetic temp cwd, outputStyle forced Default,
  --output-format json.
- **Opus is a bad grader** even hermetic: scored "5432." 0% complete and "No."
  NO on outcome-first. Sonnet and Haiku both grade correctly. glance_bench now
  takes --judge-model (default sonnet), decoupled from the generator. (Parked:
  why Opus fails strict-label grading.)
- **Sonnet gen+judge, 3 trials, Default vs v1 vs v2** (glance_sonnet_v1_v2.json):
  glance_pass doesn't separate styles (0.65-0.69; long replies still lead with
  the outcome and are complete). The separating axis is WORDS: Default 88.5,
  v1 78.9, v2 63.1 at flat completeness (~89). v2 delivers the vision's shape;
  raw glance_pass is the wrong headline without a word axis.
- **Known metric gap (flagged by Tahi, unbuilt):** clarifying questions and
  refusals score as misses everywhere; fine on hand-picked answerable prompts,
  wrong in general. An ambiguous-prompt arm with a 3-way judge
  (OUTCOME/CLARIFY/NEITHER) is designed but not implemented.

## v2 -> v3

v2 (say-less-v2.md): line 1 = outcome, detail behind a named offer, safety
caveats inline. Won on words (-20% vs v1, -29% vs Default) but licensed
overflow: "then only what changes their next action" plus a sanctioned offer
meant Sonnet wrote outcome + reasons + offer. Also one observed regression:
thinking out loud in the reply on a debug prompt (outcome_first=0).

v3 (say-less-v3.md): the EXAMPLES are the normative target, stated as such.
1-4 line replies; reasons default to the offer, not the reply; one swing-reason
max inline; corrected snippet counts as the fix; safety caveats never defer.

## The cheap test (spot.py) and v3's first run

Heavy harnesses (paired baselines, LLM judges, multi-trial Opus batches) hit
the session usage limit and answer questions a cheap run screens first. New
default: `spot.py` - one style, 10 session-shaped prompts, no judges, no
scores except prose words; human + Claude judge by eye against the examples.
Em dashes and completeness dropped from scoring entirely (Tahi: em dashes
don't matter; models don't return nonsense, so completeness judging isn't
worth its noise at this stage).

v3 on Sonnet, first spot run: median 39 words, range 1-82. 7/10 at
example-length. Overflows: explain (82) and how-to (Docker, 69 + list + code
+ offer, the fill-everything-inline-AND-offer failure). Fix queued for v3.1:
how-tos get the single best move inline, rest behind the offer.

## Decisions (dogfood phase)

- This project now runs **v3 style-only, hook disabled** (.claude/settings.json;
  hook config preserved under hooks_disabled). Rationale, in order: (1)
  sequencing - the goal right now is consistent example-length replies EARLY in
  the session; late-session persistence is phase 2 and the hook only solves
  phase 2; (2) hook numbers were measured against v1, and v3's examples anchor
  may drift less on its own; (3) a single style file is the far easier
  open-source sell. If late-session replies
  bloat in real use, that reproduces drift in the wild and the hook returns as
  the documented power-user add-on.
- Test protocol going forward: spot.py per iteration; heavy harnesses only at
  milestones (and one Opus spot run before trusting v3, since every finding
  says Opus behaves worse than Sonnet).
- Direction (Tahi): dogfood -> v3.1 -> one Opus check -> open source as
  style + optional hook + spot.py + results/, README told as "Claude outputs so
  much it kills the vibe; you stop reading; then you make mistakes."

## v3.1 / v3.2 iteration (same day)

- **v3.1** (principles-only, counts removed, + steals from i-have-adhd): median 56,
  worst 216. Removing the length bound was load-bearing; "complete beats short"
  read as license to expand. Regression.
- **v3.2** (= v3's bound + the steals: verbatim fix, mid-flight next action,
  substance never trimmed): median 34, 8/10 at target, worst 87. Best of the
  three; dogfooding this (settings.json). Watchpoints: how-to lists still
  overflow (~87), diff reviews still thin (missed the now() bug both rounds).
- i-have-adhd comparison (spot.py, same prompts): median 78, range 1-209.
  Action-first but verbose; its wins (verbatim commands, concrete next action)
  are absorbed into v3.2. Positioning: "it makes you act faster; Say Less makes
  you read less."
