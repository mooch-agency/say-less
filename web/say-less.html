Same model, style on

Runs on your machine on Claude. Each arm runs hermetically, with no user CLAUDE.md, settings or plugins reaching either side, so the output style is the only difference between them. Words are every whitespace-separated token containing a letter or digit, code included, because code is still reading, and they're counted in code, never by a model. The style and its benchmarks are open source at github.com/gichigi/say-less.
