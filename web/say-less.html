Both answers stream at once, so the columns fill at their real speeds. Each runs hermetically, with no user CLAUDE.md, settings or plugins reaching either side, so the output style is the only difference between them. Words are every whitespace-separated token containing a letter or digit, code included, because code is still reading. The style and its benchmarks are open source at github.com/gichigi/say-less.
